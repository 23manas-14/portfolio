# Portfolio Website

A responsive portfolio built with plain HTML, CSS and JavaScript. This is my 3rd sem tranning project.

## Customize
- `index.html`: replace "Your Name", the about text, and the GitHub/LinkedIn/email links.
- `script.js`: edit the `projects`, `skills`, `learning` lists and `MY_EMAIL` at the top.
- `style.css`: change colors in the `:root` and `[data-theme="dark"]` blocks.

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under "Branch", choose `main` and `/ (root)`, then Save.
4. Your site appears at `https://23manas-14.github.io/portfolio/`.
